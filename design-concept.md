# Design concept — Автосвет Иваново | Avtosvet Workshop

## Client / project

- Name: Автосвет Иваново | Avtosvet Workshop
- Date: 2026-11-20
- Niche: локальная мастерская ретрофита / ремонта автомобильных фар (Bi-LED, герметизация, стенд)
- Concept-ID: `2026-11-20-avtosvet-stg-diagonal-v1`
- Composition-archetype: `diagonal-technical`
- Forbidden-for-this-niche: RGB/neon show-car look; quiet-luxury black/cream/gold; cream `#F4F1EA` + terracotta + serif; purple/indigo gradients; hero + 3 equal feature cards; lead-gen quiz funnel; filmstrip «ДО/ПРОЦЕСС/ПОСЛЕ» как весь сайт; product-theater мебельного типа; generic dark SaaS glow
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Ритуал: фото/марка → оценка → вскрытие фары → Bi-LED → герметик → регулировка на стенде → проверка пучка
- Материалы: поликарбонат, герметик, линза Bi-LED, хром/маски, пыль верстака, мокрый асфальт
- Место / свет: бокс Иваново, Станкостроителей 2г; холодный LED ~6500K; янтарь лампы на столе; ночная дорога
- Vernacular: Bi-LED, СТГ, запотевание, Lightway / Luxsar, стенд, японский→европейский свет, «под ключ»
- Sensory: резкая граница пучка, запах герметика, гул стенда, «белый» свет вместо жёлтого галогена

## Unique thesis

1. Mood: холодная трасса + тёплый верстак — точность пучка, не тюнинг-шоу.
2. Type rationale: Permanent Marker — кистевой знак AVTO (красный) + SVET (белый); Big Shoulders Display — конденсированный трекинг WORKSHOP и заголовки секций; IBM Plex Sans (тело) + IBM Plex Mono (SKU, СТГ, стенд). В шапке — сам файл логотипа.
3. Palette logic: асфальт / корпус / холодный LED / поликарбонат; акцент — красный кисти логотипа AVTO (`#C4121A`). Янтарь верстака снят с UI: это не цвет марки.
4. Composition: `diagonal-technical` — светотеневая граница (СТГ) режет hero и кейсы; бренд = hero-signal; один headline job.
5. Motion: wipe границы пучка; мягкий bloom линзы; reveal до→после по линии СТГ (2–3 жеста).
6. Main gesture: **СТГ как структурный разрез сайта** (не декор).

## Anti-clone checklist

- [x] Carryover: не filmstrip-process (СНОВА НОВОЕ), не product-theater / chalk-oak (Sandra), не kraft/passport — своя диагональ СТГ + LED/асфальт
- [x] Benchmark clone: не RGB-neon The Lab, не cyan-glow / collage Gils, не quiz-воронка LightOS — только craft (фото, pacing, иерархия)
- [x] AI clusters: нет purple-gradient / cream+terracotta / broadsheet / dark neon SaaS / hero+3 cards
- [x] Brand test: без логотипа читается как мастерская фар / Bi-LED / пучок на асфальте — не пекарня / не bridal / не мебель
